== Executive Summary

*FastVectorDB* is a lightweight, ultra-fast, in-memory vector database and semantic memory store written in modern C++ (C++20). It is designed to serve as a low-latency memory component for local AI agents, offering high-throughput vector similarity search, SIMD acceleration, memory-mapped persistence, and a clean C-ABI for integration with external host systems.

== Core Modules

=== 1. Memory Layout & Storage Core (`include/fastvectordb/vector_store.hpp`)
* **Contiguous Float Buffer:** Eliminates pointer chasing by storing vector data in a single contiguous flat array.
* **Cache Alignment:** 64-byte alignment (`alignas(64)`) to match CPU cache lines and SIMD AVX2/AVX-512 register loads.
* **Metadata Table:** Separate hash map / payload store mapping vector IDs to text content and timestamps.

=== 2. SIMD Distance Engine (`include/fastvectordb/simd_math.hpp`)
* **AVX2 / FMA Acceleration:** Processes 8 single-precision floats per instruction using 256-bit vector registers (`__m256`).
* **Cosine Similarity & L2 Distance:** Fused Multiply-Add loop for dot product calculations.
* **Scalar Fallback:** Standard C++ loop fallback when AVX2 hardware flags are not present.

=== 3. Binary Persistence & `mmap` (`include/fastvectordb/persistence.hpp`)
* **Zero-Copy File Mapping:** Direct binary `mmap` system calls to load indices into memory without parsing.
* **Binary Header:** Magic bytes (`VECDB`), dimension count, total vector count, and precision flags.

=== 4. C-ABI Gateway (`include/fastvectordb/c_api.h`)
* **Standard C Exports:** `extern "C"` functions (`vdb_create`, `vdb_insert`, `vdb_search_knn`, `vdb_destroy`).
* **FFI Ready:** Compatible with Python `ctypes`/`cffi`, Rust, or any local agent framework.
