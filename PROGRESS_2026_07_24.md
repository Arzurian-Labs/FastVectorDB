## 💡 User Pseudocode Log & C++ Syntax Evolution

During development, the user designed the engine logic using pseudocode before translating it into C++20 code.

### 1. Constructor & Guard Clause Pseudocode
> **User Pseudocode:**
> ```cpp
> ... VectorStore::VectorStore(std::size_t dimension, ... (same std declare at three dots) initial_capacity);
> ... dimension::dimension_(Declare anything that needs to be written here );
> Using a if-else statement to check:
> if(dimension_ == 0) { std::invalid_argument;
> std::cout << "Vector dimension must be greater than zero." << std::endl;
>  }
> else {
> This is where dimension creation would be created so long as it is above 0 (not below 0)
> }
> ```
* **Architectural Concept:** **Guard Clause / Early Exit pattern.** Checking `dimension_ == 0` first and throwing an exception avoids nested `if-else` blocks.
* **C++ Translation:**
  ```cpp
  VectorStore::VectorStore(std::size_t dimension, std::size_t initial_capacity)
      : dimension_(dimension)
  {
      if (dimension_ == 0) {
          throw std::invalid_argument("VectorStore::VectorStore: dimension must be greater than 0.");
      }
      if (initial_capacity > 0) {
          data_.reserve(initial_capacity * dimension_);
          ids_.reserve(initial_capacity);
      }
  }
  ```

* **Architectural Concept:** Separating declarations (`.hpp`) from definitions (`.cpp`), declaring `const` getters, and validating vector dimensions during insertion.
* **C++ Translation:**
  ```cpp
  std::size_t VectorStore::dimension() const { return dimension_; }
  std::size_t VectorStore::size() const { return ids_.size(); }

  void VectorStore::insert(std::uint64_t id, const std::vector<float>& vec) {
      if (vec.size() != dimension_) {
          throw std::invalid_argument("VectorStore::insert: vector size does not match dimension.");
      }
      data_.insert(data_.end(), vec.begin(), vec.end());
      ids_.push_back(id);
  }
  ```

## 🧠 C++ Concepts & Lessons Learned

1. **Header vs. Source Separation:**
   * `.hpp` holds class declarations inside `class VectorStore { public: ... private: ... };`.
   * `.cpp` holds method implementations prefixed with `VectorStore::` inside `namespace fastvectordb`.
2. **Constructors & `explicit`:**
   * Constructors do not have return types.
   * `explicit` prevents implicit type conversions (e.g. converting `384` into a `VectorStore`).
3. **Member Initializer Lists:**
   * `: dimension_(dimension)` initializes members before the constructor body executes.
4. **Const Correctness (`const` getters):**
   * `std::size_t size() const;` guarantees the method does not mutate internal class state.
5. **Pass by Const Reference (`const std::vector<float>&`):**
   * Avoids copying large float arrays on function calls.
6. **Pre-Allocation with `.reserve()`:**
   * Calling `data_.reserve(initial_capacity * dimension_)` prevents dynamic memory reallocation overhead during vector insertion.
