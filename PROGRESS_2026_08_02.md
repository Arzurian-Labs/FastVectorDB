## Accomplishments

### 1. VectorStore Contiguous Memory Accessors
- **`get_vector(index)`**: Computes `&data_[index * dimension_]` to return a 1D float pointer to the vector at `index`. Includes index boundary validation (`std::out_of_range`).
- **`data()`**: Returns a raw constant pointer to the contiguous float buffer (`data_.data()`).
- **`ids()`**: Returns a constant reference to the vector ID list (`ids_`).
